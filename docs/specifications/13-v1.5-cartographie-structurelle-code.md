\# CONTEXTFORGE  
\#\# 13 — V1.5 : Cartographie structurelle du code  
\*\*Version 1.0 — Spécification officielle\*\*

\#\# 1\. Objectif  
Transformer ContextForge d’un générateur de Context Packs en outil capable de comprendre structurellement un projet TypeScript/JavaScript sans IA.

\#\# 2\. Fonctionnalités  
\- analyse AST ;  
\- extraction des imports et exports ;  
\- extraction des classes, interfaces, fonctions, méthodes, types et enums ;  
\- détection des routes HTTP ;  
\- détection des tests associés ;  
\- graphe de dépendances ;  
\- navigation fichier → symbole → dépendances ;  
\- génération de diagrammes Mermaid ;  
\- classification heuristique des fichiers.

\#\# 3\. Architecture  
\`\`\`text  
packages/  
├── code-model/  
├── analyzers/  
│   ├── typescript/

\#\# 5\. Classification sans IA  
Chaque rôle est déduit par règles explicites :  
\- suffixe \`.controller.ts\` → controller ;  
\- dossier \`application/use-cases\` → use case ;  
\- interface nommée \`\*Repository\` → repository contract ;  
\- import Fastify dans \`interfaces/http\` → route/controller ;  
\- fichier \`\*.spec.ts\` → test.

Le résultat inclut une confiance et une justification.
