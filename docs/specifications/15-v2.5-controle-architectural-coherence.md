\# CONTEXTFORGE  
\#\# 15 — V2.5 : Contrôle architectural et détection d’incohérences  
\*\*Version 1.0 — Spécification officielle\*\*

\#\# 1\. Objectif  
Vérifier automatiquement que le projet respecte ses règles d’architecture, de nommage, de documentation et de test.

\#\# 2\. Moteur de règles  
Règles YAML/JSON versionnées dans \`.contextforge/rules.yaml\`.

\#\# 3\. Types de règles  
\- dépendances autorisées/interdites ;  
\- couches et frontières ;  
\- conventions de nommage ;  
\- emplacement des fichiers ;  
\- présence de tests ;  
\- imports de frameworks interdits dans le domaine ;  
\- cycles ;  
\- fichiers orphelins ;  
\- routes sans validation ;  
\- documents référant des fichiers absents ;  
\- décisions d’architecture non respectées.

\#\# 4\. Exemple  
\`\`\`yaml  
layers:  
  domain:  
    match: "\*\*/domain/\*\*"  
    forbidImports:  
      \- "fastify"  
      \- "\*\*/infrastructure/\*\*"

testing:  
  requireTestFor:  
    \- "\*\*/\*.use-case.ts"  
\`\`\`

\#\# 5\. Finding  
\- id  
\- ruleId  
\- severity  
\- message  
\- evidence  
\- relativePath  
\- lineNumber  
\- remediation  
\- confidence  
\- firstSeen  
\- lastSeen  
\- status

\#\# 6\. Diagnostics  
\- erreur ;  
\- avertissement ;  
\- information ;  
\- exception acceptée avec justification.

\#\# 7\. Intégration VS Code  
\- Diagnostics API ;  
\- Problems panel ;  
\- code actions sûres ;  
\- navigation vers la règle ;  
\- suppression locale justifiée ;  
\- rapport Markdown.

\#\# 8\. Détection de documentation obsolète  
Heuristiques :  
\- référence à un fichier supprimé ;  
\- document plus ancien que les fichiers liés ;  
\- route ou symbole mentionné mais absent ;  
\- diagramme listant un module supprimé ;  
\- changement important depuis la dernière validation.

\#\# 9\. Limites  
Le moteur ne prétend pas comprendre toute la sémantique métier. Il signale des incohérences observables et explique ses preuves.

\#\# 10\. Critères de sortie  
\- règles personnalisables ;  
\- résultats déterministes ;  
\- faux positifs contrôlables ;  
\- aucune correction destructive automatique ;  
\- rapport clair et traçable.
