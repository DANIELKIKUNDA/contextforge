\# CONTEXTFORGE  
\#\# 17 — V3.5 : Recherche locale, Git et documentation vivante  
\*\*Version 1.0 — Spécification officielle\*\*

\#\# 1\. Objectif  
Permettre de retrouver rapidement toute information technique et de suivre l’évolution du projet dans le temps.

\#\# 2\. Recherche locale  
\- plein texte ;  
\- recherche par symbole ;  
\- recherche par rôle ;  
\- recherche par route ;  
\- recherche par décision ;  
\- recherche par finding ;  
\- filtres par module, couche, date et statut.

\#\# 3\. Index  
\- FTS5 SQLite ou index local équivalent ;  
\- index incrémental ;  
\- normalisation ;  
\- snippets ;  
\- classement BM25 ;  
\- aucune dépendance cloud.

\#\# 4\. Intégration Git  
\- fichiers modifiés ;  
\- diff ;  
\- commits associés ;  
\- auteur local lorsque disponible ;  
\- comparaison branche courante/base ;  
\- détection des zones à documenter ;  
\- snapshot avant/après.

\#\# 5\. Documentation vivante  
\- lier documents et artefacts ;  
\- marquer une documentation comme validée ;  
\- signaler les changements depuis validation ;  
\- générer index, cartes et tables structurelles ;  
\- créer rapports de mise à jour ;  
\- ne jamais réécrire automatiquement un document métier sans confirmation.

\#\# 6\. Cas d’usage  
\- SearchProjectKnowledge  
\- CompareGitChanges  
\- FindImpactedDocuments  
\- ValidateDocumentSnapshot  
\- GenerateChangeReport

\#\# 7\. Sorties  
\`\`\`text  
.contextforge/reports/  
├── change-report.md  
├── stale-documents.md  
├── impacted-tests.md  
└── release-context.md  
\`\`\`

\#\# 8\. Critères de sortie  
\- recherche rapide ;  
\- résultats traçables ;  
\- comparaison Git fiable ;  
\- détection d’obsolescence explicable ;  
\- aucune API externe obligatoire.
