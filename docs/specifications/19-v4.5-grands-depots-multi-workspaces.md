\# CONTEXTFORGE  
\#\# 19 — V4.5 : Grands dépôts, monorepos et multi-workspaces  
\*\*Version 1.0 — Spécification officielle\*\*

\#\# 1\. Objectif  
Garantir que ContextForge reste utilisable sur des dépôts volumineux et sur des machines modestes.

\#\# 2\. Contraintes  
\- millions de lignes ;  
\- dizaines de milliers de fichiers ;  
\- plusieurs packages ;  
\- workspaces VS Code multiples ;  
\- RAM limitée ;  
\- interruptions possibles.

\#\# 3\. Techniques  
\- indexation incrémentale ;  
\- files d’attente ;  
\- parallélisme borné ;  
\- streaming ;  
\- cache disque ;  
\- pagination ;  
\- reprise après interruption ;  
\- priorisation des fichiers visibles ;  
\- analyse à la demande ;  
\- budgets CPU/RAM.

\#\# 4\. Monorepos  
\- détection pnpm/npm/yarn/Turbo/Nx ;  
\- graphe package-level ;  
\- limites par package ;  
\- profils par workspace ;  
\- chemins normalisés ;  
\- dépendances internes.

\#\# 5\. Multi-workspaces  
\- plusieurs racines ;  
\- identité stable par workspace ;  
\- mémoire séparée ou fédérée ;  
\- règles globales et locales ;  
\- Context Packs multi-racines contrôlés.

\#\# 6\. Observabilité locale  
\- durée par phase ;  
\- mémoire utilisée ;  
\- fichiers analysés ;  
\- cache hit rate ;  
\- erreurs ;  
\- annulation ;  
\- export diagnostic local.

\#\# 7\. Tests de performance  
\- petits projets ;  
\- projets moyens ;  
\- grands monorepos ;  
\- machines 8 Go RAM ;  
\- disques lents ;  
\- scans interrompus ;  
\- cache froid/chaud.

\#\# 8\. Critères de sortie  
\- VS Code non bloqué ;  
\- mémoire plafonnée ;  
\- reprise fiable ;  
\- progression exacte ;  
\- résultats stables ;  
\- dégradation contrôlée.
